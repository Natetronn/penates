## Install

<Tabs syncKey="os">
  <TabItem label="Linux">
    Find your distribution. For the `.deb`, `.rpm` and AppImage, download the file from the
    [releases page](https://github.com/Natetronn/penates/releases/latest) first. "In Penates" means it updates itself: new versions appear under **Updates**,
    signed and checked before they install.

    | Distribution | Install | Updates |
    |---|---|---|
    | Arch Linux | `paru -S penates-bin` or `yay -S penates-bin`, or without a helper: see below | your AUR helper |
    | CachyOS | `paru -S penates-bin` | `paru -Syu` |
    | Debian | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | elementary OS | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | EndeavourOS | `yay -S penates-bin` | `yay -Syu` |
    | Fedora | `sudo dnf install ./penates-*.x86_64.rpm` | in Penates |
    | Garuda Linux | `paru -S penates-bin` | `paru -Syu` |
    | Linux Mint | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | Manjaro | `pamac build penates-bin` (AUR support on in Pamac) | `pamac upgrade -a` |
    | openSUSE | `sudo zypper install --allow-unsigned-rpm ./penates-*.x86_64.rpm` | in Penates |
    | Pop!_OS | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | Ubuntu | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | Zorin OS | `sudo apt install ./penates_*_amd64.deb` | in Penates |
    | Any other | the AppImage: `chmod +x penates_*_amd64.AppImage && ./penates_*_amd64.AppImage` | in Penates |

    **On Arch and its relatives** the AUR has two packages, and they replace each other: `penates-bin` is the
    prebuilt release (installs in seconds, recommended), `penates` builds on your computer from the release's
    source (a few minutes). Without an AUR helper, use the tools every Arch system has; pacman installs what
    makepkg builds, and `git pull && makepkg -si` in that folder updates it:

    ```sh
    sudo pacman -S --needed git base-devel   # once
    git clone https://aur.archlinux.org/penates-bin.git
    cd penates-bin
    makepkg -si
    ```

    Each release also has an Arch package for pacman alone (it does not update by itself):
    `sudo pacman -U ./penates-bin-*-x86_64.pkg.tar.zst`.

    **From source, with git (any distribution).** On Arch, the repo's own PKGBUILD builds and installs your
    checkout:

    ```sh
    sudo pacman -S --needed git base-devel rustup webkit2gtk-4.1 libayatana-appindicator
    rustup default stable
    git clone https://github.com/Natetronn/penates && cd penates/packaging/arch
    makepkg -si
    ```

    Elsewhere, install Rust (from [rustup.rs](https://rustup.rs/)) and the WebKitGTK development files
    (Debian and Ubuntu: `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev build-essential pkg-config`;
    Fedora: `webkit2gtk4.1-devel libappindicator-gtk3-devel librsvg2-devel gcc`), then build a tarball and
    install it for your user:

    ```sh
    git clone https://github.com/Natetronn/penates && cd penates
    ./scripts/make-tarball.sh
    tar -xzf dist/penates-*.tar.gz -C /tmp && PREFIX=$HOME/.local /tmp/penates-*/install.sh
    ```
  </TabItem>
  <TabItem label="Windows">
    Download the installer from the [releases page](https://github.com/Natetronn/penates/releases/latest) and run it. It installs Penates for your user, and
    Penates updates itself: new versions appear under **Updates**, signed and checked before they install.

    | Windows | Download | Updates |
    |---|---|---|
    | Windows 11 | `Penates_<version>_x64-setup.exe` | in Penates |
    | Windows 10 | the same installer; if Microsoft Edge WebView2 is missing, it downloads it | in Penates |

    <Aside type="caution" title="First launch">
      The installer is not signed with a Microsoft certificate yet, so SmartScreen may say it protected your PC.
      Choose **More info → Run anyway**.
    </Aside>
  </TabItem>
  <TabItem label="macOS">
    Download the `.dmg` for your Mac from the [releases page](https://github.com/Natetronn/penates/releases/latest), open it and drag Penates to Applications.
    It needs macOS 14 (Sonoma) or later, and updates itself: new versions appear under **Updates**, signed and
    checked before they install.

    | Mac | Download | Updates |
    |---|---|---|
    | Apple silicon (M1 and later) | `Penates_<version>_aarch64.dmg` | in Penates |
    | Intel | `Penates_<version>_x64.dmg` | in Penates |

    Not sure which Mac you have? Apple menu → **About This Mac**: "Chip: Apple M…" is Apple silicon,
    "Processor: Intel…" is Intel.

    <Aside type="caution" title="First launch">
      Penates is not signed with an Apple certificate yet, so macOS stops it the first time. Open it once, then
      go to **System Settings → Privacy & Security** and choose **Open Anyway**.
    </Aside>
  </TabItem>
</Tabs>

Penates updates itself on Windows and macOS and as an AppImage, `.deb` or `.rpm`; the updates are signed and
checked before they install. AUR packages update with your AUR helper or `makepkg`.

## Make Your First App

<Steps>
1. Open **Penates** from your application menu.
2. Pick one under **Catalog**, or go to **Create**, paste any site's address and choose **Create app**.
3. The app appears in your application menu and opens in its own window, with its own login.
</Steps>

Or from a terminal:

```sh
penates create github.com
penates run github
```

## Good to Know

- **Links to other sites** open in your browser; the site's own pages and its sign-in popups stay in the app.
- **Keys:** Alt+← and Alt+→ (or your mouse's side buttons) go back and forward, F5 or Ctrl+R reloads, Alt+Home goes to the app's start page. F1 or Ctrl+/ shows these keys in any app.
- **The toolbar** above each site has back, forward, reload, start page, the address, the key list and Open in
  browser, in the site's own color. Turn it off or pick its color under Edit → Window.
- **Each app's options** (window size, tray icon, start minimized or in the tray, permissions) are under its **Edit** button.
- **Updates** for Penates and for your apps are under **Updates**.

<Aside>
  Logins never leave the app's own storage. Exporting apps to a `.penates` file copies their settings and
  icons, never cookies or logins. See [Sharing](../docs/sharing/).
</Aside>
