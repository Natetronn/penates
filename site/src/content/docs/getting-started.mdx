## Install

<Tabs syncKey="os">
  <TabItem label="Linux">
    **Arch Linux and its relatives (CachyOS, EndeavourOS, Manjaro…): from the AUR.** Two packages, installed and
    updated like the rest of your system:

    | Package | What it is |
    |---|---|
    | `penates-bin` | the prebuilt release; installs in seconds (recommended) |
    | `penates` | built on your computer from the release's source; takes a few minutes |

    With an AUR helper, one command (updates come with `paru -Syu` or `yay -Syu`):

    ```sh
    paru -S penates-bin        # or: yay -S penates-bin
    ```

    Without a helper, with the tools every Arch system has: clone the package, build it, and pacman installs it.

    ```sh
    sudo pacman -S --needed git base-devel   # once
    git clone https://aur.archlinux.org/penates-bin.git
    cd penates-bin
    makepkg -si
    ```

    To update, run `git pull && makepkg -si` in that folder. To build from source instead, use `penates` in
    place of `penates-bin`, either way. The two replace each other, so you only ever have one.

    **Arch, without the AUR:** each release also has an Arch package. Download `penates-bin-…-x86_64.pkg.tar.zst`
    from the [releases page](https://github.com/Natetronn/penates/releases/latest) and run
    `sudo pacman -U ./penates-bin-*-x86_64.pkg.tar.zst`. It does not update by itself; install a newer one the
    same way, or switch to the AUR.

    **Other distributions:** from the [releases page](https://github.com/Natetronn/penates/releases/latest):

    ```sh
    sudo apt install ./penates_*_amd64.deb         # Debian, Ubuntu, Mint, Pop!_OS
    sudo dnf install ./penates-*.x86_64.rpm        # Fedora, openSUSE (zypper install …)
    chmod +x penates_*_amd64.AppImage && ./penates_*_amd64.AppImage   # anywhere
    ```

    These three update themselves: Penates offers new versions under **Updates**, signed and checked before they
    install.

    **From source, with git:** on Arch, the repo's own PKGBUILD builds and installs your checkout:

    ```sh
    sudo pacman -S --needed git base-devel rustup webkit2gtk-4.1 libayatana-appindicator
    rustup default stable
    git clone https://github.com/Natetronn/penates && cd penates/packaging/arch
    makepkg -si
    ```

    Elsewhere, install Rust (from [rustup.rs](https://rustup.rs/)) and the WebKitGTK development files
    (Debian and Ubuntu: `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev build-essential pkg-config`;
    Fedora: `webkit2gtk4.1-devel libappindicator-gtk3-devel librsvg2-devel gcc`), then build a tarball and install it
    for your user:

    ```sh
    git clone https://github.com/Natetronn/penates && cd penates
    ./scripts/make-tarball.sh
    tar -xzf dist/penates-*.tar.gz -C /tmp && PREFIX=$HOME/.local /tmp/penates-*/install.sh
    ```
  </TabItem>
  <TabItem label="Windows">
    Run the installer from the [releases page](https://github.com/Natetronn/penates/releases/latest). If
    SmartScreen says it protected your PC, choose **More info → Run anyway**: the installer is not signed with
    a Microsoft certificate yet.
  </TabItem>
  <TabItem label="macOS">
    Open the `.dmg` from the [releases page](https://github.com/Natetronn/penates/releases/latest) and drag
    Penates to Applications (macOS 14 or later). The first time, allow it under **System Settings → Privacy &
    Security → Open Anyway**: it is not signed with an Apple certificate yet.
  </TabItem>
</Tabs>

Penates updates itself on Windows and macOS and as an AppImage, `.deb` or `.rpm`; the updates are signed and
checked before they install. AUR packages update with your AUR helper or `makepkg`.

## Make your first app

<Steps>
1. Open **Penates** from your application menu.
2. Go to **Create**. Pick one from **Popular apps**, or paste any site's address and choose **Create app**.
3. The app appears in your application menu and opens in its own window, with its own login.
</Steps>

Or from a terminal:

```sh
penates create github.com
penates run github
```

## Good to know

- **Links to other sites** open in your browser; the site's own pages and its sign-in popups stay in the app.
- **Keys:** Alt+← and Alt+→ (or your mouse's side buttons) go back and forward, F5 or Ctrl+R reloads, Alt+Home goes to the app's start page. F1 or Ctrl+/ shows these keys in any app.
- **A toolbar** with back, forward, reload, start page and the address: Edit → Window → **Show a toolbar**.
- **Each app's options** (window size, tray icon, start minimized or in the tray, permissions) are under its **Edit** button.
- **Updates** for Penates and for your apps are under **Updates**.

<Aside>
  Logins never leave the app's own storage. Exporting apps to a `.penates` file copies their settings and
  icons, never cookies or logins. See [Sharing](../docs/sharing/).
</Aside>
